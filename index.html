Pedro Tavares

I started my career as a CGI generalist, working on short films, commercials and web-based animations. Then I landed a job working with Flash creating web-banners for the entertainment industry. Once the Flash era ended, I moved to HTML5 and CSS3, and I have been working with these technologies ever since.

Over the years I have worked in many different projects with many different tech setups and team sizes: from small static webisites to large web applications, interactive screens for trade shows, gamified experiences, mobile-first designs and 3D visualisations. The only constant in all these projects has been the need to adapt and learn. I am confident in my ability to absorb new information and work with it.

Projects as a frontend developer.

  1. Above Surveying

    In charge of the company's main client application frontend code, reviewing and giving feedback on UI and UX decisions.

    Championed the implementation of component-based architecture for the UI elements, encouraged the use of Storybook for UI component development. Implemented and mentored others in the use of Playwright and Percy for E2E testing and the importance of visual regression testing.

  2. Absurd

    Built static and dynamic Vue components for a large payment processing platform consuming REST API endpoints. Worked alongside Umbraco develpoers to implement these components into Umbraco's Razor templates. Aslo improved the HTML and CSS structure in several previously built components.

  3. RPAIR

    Responsible for the frontend development of a web application that allows users to manage and track their watch and jewelry repair requests. Introduced the BEM methodology and implemented SASS, dramatically reducing the fileweight and complexity of the CSS codebase. Also reduced the JavaScript payload and improved the page's performance. Introduced E2E testing using Cypress and the use of Svelte for the dynamic components of the website. Consolidated repeated PHP into reusable customizable partials and removed redundant code.

  4. Postscript Medical

    Sole developer and infrastructure architect, responsible for the full technical delivery of an MVP trialled by two London NHS hospitals; the trial was well received, with some adoption of the tool among trial users.

  5. Branhill Computing Limited

    Worked as part of a team on Silm4 a web-based reimplementation of a legacy Java stock management system used by large, global companies.

  6. The Team

    Built a microsite for their client Arcadis of a interactive 3D map two stylized cities showcasing transportation technologies being developed for the near future. Participated in the strategy development and guided the technical choices for the project. Liaised with the client to report progress and manage expectations.

  7. KoffeeCup

    Created several interactive VueJS components and integrated them using the MapBox API for a realtime competition leaderboard ran by Redbull. Liaised with a remote team of frontend and backend developers helping integrate the different sections of a multi-language PHP-based website.
