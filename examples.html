Language of flowers

This was a project I did in 2017, while contracting for Kota Creative. It allows the user to create a bouquet of flowers and send it as a message based on the flowers chosen.

The project was built with React and, and it was one of my first experience with the framework.

You can see a live stripped down version of the original project and see the 2017 code in Github. You can also see a live revamped version of the project I did in 2026 with the contemporary version of React and the source code in Github.
